# QA Shop: тренажёр раскатки веток на стенды

Маленький интернет-магазин для тренировки рабочего процесса тестировщика:
разработчик чинит баг в отдельной ветке → тестировщик раскатывает эту ветку на тестовый стенд через CI → проверяет исправление и регресс → закрывает задачу или возвращает её.

- Стенды: **DEV** и **STAGE** на GitHub Pages.
- CI: GitHub Actions, workflow **«Раскатка ветки на стенд»**.
- Версия сборки видна внизу страницы и в файле `version.json` на стенде.

## Подготовка (один раз)

1. Нажми **Fork** вверху страницы. Сними галочку **Copy the main branch only**, иначе ветки разработчиков не скопируются.
2. В своём форке открой вкладку **Actions** и нажми **I understand my workflows, go ahead and enable them**.
3. Раскатай `main` на DEV (как это сделать, ниже). Первый запуск создаст ветку `gh-pages`.
4. Открой **Settings → Pages**. В **Source** выбери **Deploy from a branch**, ветку **gh-pages** и папку **/ (root)**, нажми **Save**.
5. Через 1–2 минуты стенды откроются по адресу `https://<твой-ник>.github.io/qa-stands-trainer/`.

## Как раскатить ветку на стенд

1. Вкладка **Actions** → слева **Раскатка ветки на стенд** → справа **Run workflow**.
2. В поле **Какую ветку раскатить** впиши имя ветки, в **На какой стенд** выбери `dev` или `stage`.
3. Нажми **Run workflow** и дождись зелёной галочки.
4. Подожди 1–2 минуты (GitHub Pages обновляется не мгновенно) и открой стенд.
5. Внизу страницы проверь сборку: ветка и коммит должны совпадать с тем, что ты раскатывал. Если там старая сборка, обнови страницу без кеша (Ctrl+Shift+R / Cmd+Shift+R).

Список веток: **Code → Branches** или кнопка с названием ветки над файлами.
